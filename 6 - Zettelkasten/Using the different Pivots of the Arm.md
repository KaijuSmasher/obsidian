# Using the different Pivots of the Arm
The arm is made up of three major joints and when we want to manipulate an object in space with it we can bend the arm along the following pivots:
- Wrist
- Elbow
- Shoulder

The range of motion which is achievable is dependent on which pivot of the arm we chose to use.
When drawing only with the wrist pinned in place it enables us to make precise and tight strokes, but arcs over longer distances, which makes it less ideal for longer strokes.

![[Pivots of the Arm.jpg]]

When drawing with the whole arm, where we use every pivot, especially the shoulder, it enables us to make smooth, fluid linework, even smaller marks, because it allows us to achieve straight and clean strokes over longer trajectories and it minimizes wobbling. The shoulder is the most important pivot of the arm when it comes to drawing and it's very important to use it to improve the control over the muscle we have. 
While using the shoulder to draw it's important to not anchor the elbow on the table because it locks the range of movement we would otherwise have. It's okay to rest the side of the hand, or a finger, gently on the page, as long as we don't slip back into using the wrist.
